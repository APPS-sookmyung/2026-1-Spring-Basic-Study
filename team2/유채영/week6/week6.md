# 색션 7 : 클래스 설계 규칙과 어노테이션

## IoC의 시작
스프링 프레임워크에게 객체의 생명주기(생성부터 관리까지)를 전적으로 맡기는 과정입니다.

### 스프링 빈(Sprint Bean) 등록의 의미
* "이 클래스를 이제 스프링 빈으로 관리해줬으면 좋겠어"
* "스프링 컨테이너에 이 클래스를 객체로 생성해서 등록해줘"

## 객체 등록의 두 가지 방법
1. **`@Component` 활용 (가장 일반적)**
   * 클래스 선언부 위에 어노테이션을 붙여 해당 클래스를 직접 스캔 대상으로 지정
    ```java
    @component
    class MyService { }
    ```
2. **`@Configuration`+`@Bean` 활용 (설정 클래스 방식)
    * 외부 라이브러리나 세밀한 설정이 필요한 객체를 등록할 때 사용
  

# 색션 8 : Spring Web의 동작 원리

## Apache Tomcat
Spring Boot는 내장된 Apache Tomcat을 통해 웹 서비스를 구동한다.
* **개념:** 인터넷 세상에서 우리만의 가상의 공간(웹 서버)을 만들어준다.
* **주소(URL):** http://localhost (내 컴퓨터 내부 가상 공간)
* 포트(Port): 8080
  * 네트워크를 통해 들어오는 요청이 내 컴퓨터의 여러 프로세스 중 'Tomcat'이라는 구역으로 들어올 수 있게 연결해주는 번호

## Controller와 핸들러 메서드
사용자의 요청을 직접 맞이하고 적절한 로직으로 연결해주는 관문이다.

1. `@Controller`
    * **역할:** 스프링에서 "이 클래스를 빈으로 등록함과 동시에, 웹 요청을 처리하는 컨트롤러로 사용하겠다"고 선언하는 것
    * **특징:** 내부적으로 `@Component` 기능을 포함하고 있어 자동으로 빈 등록이 이루어집니다.
2. 핸들러 메서드 (Handler Method)
    * **역할:** 컨트롤러 내에서 특정 URL 요청이 들어왔을 때 실행되는 실제 메서드
    * **특징:** 사용자의 요청에 의해 자동으로 호출되는 메소드
    * **일반 메서드:** 개발자가 코드상에서 직접 이름을 불러 호출
