Spring Basic Week 2

Spring Boot

Spring Boot는 거의 대부분이 Java 기반으로 동작하는 프레임워크라, 공부하다 막히면 스프링 자체보다 Java 문법이나 객체지향 이해 부족 때문인 경우가 많다.
또한 복잡한 설정을 자동화해주기 때문에 전체 구조를 이해하며 빠르게 웹 개발을 시작하기 좋다.

⸻

웹(Web)이란?

웹은 전 세계 사람들이 정보를 쉽게 공유하고 접근할 수 있도록 만들어진 공간이다.
최초의 웹은 CERN의 info.cern.ch에서 시작되었고, 처음에는 텍스트 중심의 단순한 구조였다.

정식 명칭은 WWW (World Wide Web) 이며, 인터넷 위에서 정보를 연결하고 공유하는 대표적인 서비스이다.

웹은 결국 모두를 위한 정보 공유 공간이다.

⸻

HTML

HTML은 Hyper Text Markup Language의 약자로, 웹 페이지의 구조를 정의하는 가장 기본적인 언어이다.
제목, 본문, 링크 등을 태그로 표현하며 브라우저가 이를 해석해 화면에 보여준다.

<h1>안녕하세요</h1>
<p>안녕하세요</p>


⸻

Web vs Internet
	•	Internet: 전 세계의 컴퓨터와 네트워크를 연결한 거대한 통신망
	•	Web: 인터넷 위에서 정보를 공유하는 공간

즉 인터넷이 기반 기술이라면, 웹은 그 위에서 동작하는 서비스라고 볼 수 있다.

⸻

HTTP

HTTP는 Hyper Text Transfer Protocol의 약자로, 브라우저와 서버가 데이터를 요청하고 응답할 때 따르는 통신 규약이다.

쉽게 말하면 인터넷 세상에서 데이터를 주고받기 위한 약속이다.

브라우저가 서버에 요청을 보내고, 서버가 HTML이나 데이터를 응답하는 과정이 모두 HTTP 규칙을 따른다.

⸻

정리

Spring Boot를 제대로 이해하려면 결국 웹의 구조(Web, HTML, Internet, HTTP) 를 먼저 이해하는 것이 중요하다.
